Your n8n chat,
with cards.

A drop-in replacement for n8n's chat widget. Same setup, same Chat Trigger, and your workflow can answer with an order, a booking, a product or the weather, drawn as a card.

  • Free, open source, MIT
  • Works with any n8n Chat Trigger
  • One script tag, or npm
Try it:

A live demo: the widget from npm, talking to a stand-in for an n8n webhook.

A card is a code block your workflow writes

n8n's chat only carries text, so the card travels as text: a code block whose language names the card, holding its fields as JSON. This widget draws it; any other chat shows the block as code, under the sentence that comes before it.

Eleven cards: weather, order (bookings too), product, place, items, stats, stock, plan, score, media, link. Each is fetched the first time an answer uses it.

Build the block in a Code node from your tool's real result, rather than asking the model to write JSON: it is exact every time, and a setting can turn it off.

Install

Coming from @n8n/chat: change the two URLs. Everything else carries over.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@aparte/n8n-chat@0/dist/style.css">
<script type="module">
  import { createChat } from 'https://cdn.jsdelivr.net/npm/@aparte/n8n-chat@0/dist/cdn/n8n-chat.js';
  createChat({
    webhookUrl: 'https://your-n8n.example.com/webhook/…/chat',
    // Optional: what the visitor is looking at, for your workflow to read.
    metadata: { page: location.href, title: document.title },
  });
</script>

A block in the page instead of a button in the corner: mode: 'embedded' with a target that has a height. Every option is in the README.
